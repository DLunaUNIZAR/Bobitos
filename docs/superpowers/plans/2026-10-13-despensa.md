# Despensa (plan 1) — Plan de implementación

> **Para agentes:** se ejecuta con `delegating-plan-execution`. Es un **plan grande** (6 tareas): pasos 1 a 6, **con `simplify`**. Cada tarea la hace un subagente `sonnet`, en serie y en orden. La revisión final la hace `opus` (si falla, `fable`). **Solo la Tarea 1 toca `firestore.rules`** (permisos); ninguna toca `migrations/`. Los pasos usan casillas (`- [ ]`).

**Objetivo:** cada espacio tiene una Despensa (en «Más») que dice qué hay en casa, se llena con un selector múltiple, se mantiene sola al marcar comprado en la Compra y ofrece «A la compra» al decir «Se acabó».

**Arquitectura:**
- **Datos:** `spaces/{spaceId}/pantryItems/{pantryId}`, un documento por cosa que hay (que exista es «hay»; «Se acabó» lo borra; nunca se edita). El id es `slug(shoppingMatchKey(name))`, así que no hay duplicados.
- **Repositorio:** `PantryRepository` (escucha, lectura del servidor, alta en lote, baja en lote) con su implementación en Firestore y un doble a mano.
- **Comprado → despensa:** `ShoppingRepository.setPurchased` gana una `PantryEntry` opcional y la apunta (o la quita al desmarcar, si la trajo esa compra) **en la misma transacción**. Quién decide si el artículo es un ingrediente es `ShoppingViewModel`, con `pantryEntryFor`.
- **Pantalla:** `feature/pantry` (lista agrupada por las 14 categorías del catálogo, buscador, «Se acabó» → Snackbar «A la compra», selector múltiple a pantalla completa).
- **Arreglo de paso:** borrar un espacio vacía todas sus subcolecciones (hoy se dejaba `notes` y `activities`), con una lista que un test mantiene igual a las reglas.

**Stack:** Kotlin + Jetpack Compose (Material 3) + Hilt + Firestore; reglas de Firestore con tests en el emulador (`@firebase/rules-unit-testing`, `node --test`).

**Spec:** `docs/superpowers/specs/2026-10-13-despensa-design.md`, secciones 1, 2 (sin «¿Qué cocino?»), 3a, 3b y 5. Este plan es el **plan 1** de la sección 7.

## Rulings de planificación

1. **Id y ejemplos.** `pantryId(name) = slug(shoppingMatchKey(name))`. La clave tolerante también quita la «-e» final, así que «Tomates» y «tomate» dan `tomat`, «Aceite de oliva» da `aceit-oliva` y «Papel de cocina» da `cocina-papel`. Los ids no se ven en la app. La spec se corrige con estos ejemplos en el commit del plan.
2. **`PantryItem` no lleva `createdBy` ni `createdAt`.** Se escriben (las reglas los exigen), pero la app no los lee: así una entrada con la hora del servidor aún pendiente no desaparece de la lista.
3. **Categorías en Kotlin.** `INGREDIENT_CATEGORIES` (las 14, en el orden de `scripts/catalog/ingredients.mjs`) pasa a `core/model`, con un test que la compara con la de Node.
4. **Borrar un espacio.** `SPACE_CHILD_COLLECTIONS` sustituye a la lista fija de `deleteSpace`; `SpaceDeletionCollectionsTest` exige que sea igual a las subcolecciones que `firestore.rules` abre dentro de `spaces/{spaceId}`. La prueba del EMU de la spec («borrar un espacio vacía…») se cambia por este test JVM: `deleteSpace` es código del cliente contra Firestore y las reglas ya dejan borrar a cualquier miembro activo.
5. **Alta en lote.** `PantryRepository.add` valida cada entrada, quita las repetidas por id y escribe en transacciones de 100 como máximo; en cada una comprueba que el espacio existe, lee los documentos y solo crea los que faltan.
6. **Una entrada no válida no impide la compra.** `setPurchased` descarta la `PantryEntry` si no pasa `validatePantryEntry` (sin letras, más de 120) y marca el artículo igual.
7. **Catálogo al marcar comprado.** `ShoppingViewModel` usa `ingredientData` si el editor ya lo cargó; si no, lee `ingredientSource.data().first()` **una vez**, con 5 s como máximo, y lo guarda mientras viva el ViewModel. Sin catálogo a tiempo, el artículo se marca sin entrada.
8. **«Se acabó».** Quita la entrada sin pedir confirmación ni ofrecer «Deshacer»; el Snackbar (`SnackbarDuration.Long`) ofrece **«A la compra»**. Si se pierde, se apunta a mano.
9. **«A la compra»** (`pantryRestock`): lee la lista del **servidor** (`currentItems`); pendiente → no escribe y avisa «Ya estaba en la lista de la compra»; comprado → `ShoppingWrite.Change(relist = true)` conservando cantidad, notas, tienda y marca; nuevo → `ShoppingWrite.Add` sin cantidad, con la marca y la tienda de `defaultSelection()`. Las marcas y tiendas se leen con 5 s como máximo; sin ellas, se apunta sin marca ni tienda.
10. **El selector vive en el ViewModel** (`PantryUiState.picker`), así sobrevive a una rotación. Mientras está abierto se escucha `IngredientShoppingSource`. Lo ya presente sale marcado y deshabilitado. La fila de texto libre («Añadir «…»») sale si lo escrito no es un ingrediente (por clave tolerante), ni algo que ya está, y se puede apuntar (id no vacío, ≤120).
11. **Orden y grupos.** Las 14 categorías en su orden y «Otros» al final (sin categoría o con una que no es de la lista); dentro, orden alfabético del español sin distinguir mayúsculas ni tildes.
12. **Destino.** `BobitosDestination.Pantry` (ruta `pantry`, icono `Icons.Rounded.Inventory2`) va al final de `moreDestinations` y a `protectedRoutes`, como Notas; su pantalla tiene barra propia con «Atrás».

```kotlin
package com.dlunaunizar.bobitos.core.model

/** Algo que hay en la despensa del espacio (`spaces/{spaceId}/pantryItems/{id}`); su `id` es [pantryId] de [name]. */
data class PantryItem(
    val id: String,
    val name: String,
    /** Categoría del catálogo (o la del ingrediente personal); `null` u otra que no es de la lista van a «Otros». */
    val category: String?,
    /** El artículo de la Compra cuya compra lo trajo; `null` si se apuntó a mano. */
    val shoppingItemId: String?,
)

/** Lo que se quiere apuntar en la despensa. */
data class PantryEntry(val name: String, val category: String?)

const val MAX_PANTRY_NAME_LENGTH = 120
const val MAX_PANTRY_CATEGORY_LENGTH = 60

/**
 * Id de la entrada de despensa de [name]: el slug de su clave de la Compra. «Tomates» y «tomate» dan `tomat`;
 * «Aceite de oliva», `aceit-oliva`. Vacío si el nombre no tiene letras ni números: eso no se puede apuntar.
 */
fun pantryId(name: String): String = slug(shoppingMatchKey(name))
```

```text
        && request.resource.data.keys().hasAll(["name", "createdBy", "createdAt"])

        && request.resource.data.name is string
        && request.resource.data.name.size() > 0
        && request.resource.data.name.size() <= 120
        && (request.resource.data.get("category", null) == null
          || (request.resource.data.category is string && request.resource.data.category.size() <= 60))
```

````markdown
Lo que hay en casa, compartido por los miembros del espacio. Solo guarda **si hay o no hay**: un documento por cada cosa que hay; «Se acabó» lo borra. Nunca se edita.

```text
name: string                  # 1–120; el nombre canónico del catálogo si es un ingrediente reconocido
category: string | null       # ≤60; la del ingrediente (común o personal); null o fuera de las 14 → «Otros»
createdBy: string             # uid de quien lo apuntó
createdAt: timestamp          # hora del servidor
shoppingItemId: string | null # el artículo de la Compra cuya compra lo trajo; null si se apuntó a mano
```

**Id:** `pantryId(name) = slug(shoppingMatchKey(name))`: «Tomates» y «tomate» dan `tomat`; «Aceite de oliva», `aceit-oliva`. Mismo id → sin duplicados; apuntar lo que ya está no hace nada. Un nombre sin letras ni números no se puede apuntar.

**Reglas:** leen y borran los miembros activos; crear exige la forma (`hasOnly`), `createdBy == auth.uid`, `createdAt == request.time` y un id con formato de slug (≤120); `update` está prohibido.
````

```kotlin
/** La despensa del espacio: lo que hay en casa (`spaces/{spaceId}/pantryItems`). */
interface PantryRepository {
    /** Escucha en vivo, con 1000 entradas como máximo y sin orden (lo pone la pantalla). */

    /** Ids de lo que hay, leídos del servidor: el primer snapshot de [items] puede salir de una caché vieja. */

    /** Quita las entradas [ids]; las que ya no están no dan error. */
    suspend fun remove(spaceId: String, ids: List<String>)
}

enum class PantryFailure {
    NameRequired,
    NameTooLong,
    NotAuthenticated,
    EmailNotVerified,
    SpaceNotFound,
    PermissionDenied,
    Network,
    Unknown,
}

class PantryRepositoryException(val failure: PantryFailure, cause: Throwable? = null) : Exception(cause)
```

```kotlin
package com.dlunaunizar.bobitos.data.repository

import com.dlunaunizar.bobitos.core.model.MAX_PANTRY_CATEGORY_LENGTH
import com.dlunaunizar.bobitos.core.model.MAX_PANTRY_NAME_LENGTH
import com.dlunaunizar.bobitos.core.model.PantryEntry
import com.dlunaunizar.bobitos.core.model.PantryItem
import com.dlunaunizar.bobitos.core.model.pantryId
import com.google.firebase.firestore.DocumentSnapshot
import com.google.firebase.firestore.FieldValue

// Compartido por FirestorePantryRepository y FirestoreShoppingRepository (comprado → despensa).
internal const val PANTRY_ITEMS = "pantryItems"
internal const val FIELD_PANTRY_SHOPPING_ITEM_ID = "shoppingItemId"

/**
 * Entrada lista para escribir: nombre recortado (con letras o números, 120 caracteres como máximo) y categoría
 * recortada. Una categoría vacía o de más de 60 caracteres se descarta, no falla.
 */
internal fun validatePantryEntry(entry: PantryEntry): PantryEntry {
    val name = entry.name.trim()
    val failure = when {
        pantryId(name).isEmpty() -> PantryFailure.NameRequired
        name.length > MAX_PANTRY_NAME_LENGTH -> PantryFailure.NameTooLong
        else -> null
    }
    if (failure != null) throw PantryRepositoryException(failure)
    val category = entry.category?.trim()?.takeIf { it.isNotEmpty() && it.length <= MAX_PANTRY_CATEGORY_LENGTH }
    return PantryEntry(name, category)
}

/** Campos de una entrada nueva; [shoppingItemId] es el artículo de la Compra que la trajo, o `null`. */
internal fun pantryItemFields(entry: PantryEntry, userId: String, shoppingItemId: String?): Map<String, Any?> = mapOf(
    "name" to entry.name,
    "category" to entry.category,
    "createdBy" to userId,
    "createdAt" to FieldValue.serverTimestamp(),
    FIELD_PANTRY_SHOPPING_ITEM_ID to shoppingItemId,
)

internal fun DocumentSnapshot.toPantryItem(): PantryItem? = PantryItem(
    id = id,
    name = getString("name") ?: return null,
    category = getString("category"),
    shoppingItemId = getString(FIELD_PANTRY_SHOPPING_ITEM_ID),
)
```

```kotlin
package com.dlunaunizar.bobitos.data.repository

import com.dlunaunizar.bobitos.core.model.AuthUser
import com.dlunaunizar.bobitos.core.model.PantryEntry
import com.dlunaunizar.bobitos.core.model.PantryItem
import com.dlunaunizar.bobitos.core.model.pantryId
import com.dlunaunizar.bobitos.data.sync.RealtimeMetrics
import com.dlunaunizar.bobitos.data.sync.SyncRepository
import com.google.firebase.firestore.DocumentSnapshot
import com.google.firebase.firestore.FirebaseFirestore
import com.google.firebase.firestore.FirebaseFirestoreException
import com.google.firebase.firestore.Source
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.tasks.await
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class FirestorePantryRepository @Inject constructor(
    private val authRepository: AuthRepository,
    private val syncRepository: SyncRepository,
    private val realtimeMetrics: RealtimeMetrics,
) : PantryRepository {
    private val firestore = FirebaseFirestore.getInstance()

    override fun items(spaceId: String): Flow<List<PantryItem>> =
        pantryCollection(spaceId).limit(MAX_PANTRY_ITEMS).documentsFlow(
            metrics = realtimeMetrics,
            scope = "pantry:active",
            toException = Throwable::toPantryRepositoryException,
        ) { documents -> documents.mapNotNull(DocumentSnapshot::toPantryItem) }

    override suspend fun currentIds(spaceId: String): Set<String> = runPantryOperation {
        pantryCollection(spaceId)
            .limit(MAX_PANTRY_ITEMS)
            .get(Source.SERVER)
            .await()
            .documents
            .mapTo(HashSet(), DocumentSnapshot::getId)
    }

    override suspend fun add(spaceId: String, entries: List<PantryEntry>) = runPantryOperation {
        val user = requireVerifiedUser()
        val valid = entries.map(::validatePantryEntry).distinctBy { pantryId(it.name) }
        val spaceReference = firestore.collection(SPACES).document(spaceId)
        valid.chunked(MAX_ADDS_PER_TRANSACTION).forEach { chunk ->
            firestore.runTransaction { transaction ->
                if (!transaction.get(spaceReference).exists()) {
                    throw PantryRepositoryException(PantryFailure.SpaceNotFound)
                }
                val references = chunk.map { pantryCollection(spaceId).document(pantryId(it.name)) }
                // Firestore exige hacer todas las lecturas antes de la primera escritura.
                val missing = references.map { !transaction.get(it).exists() }
                chunk.forEachIndexed { index, entry ->
                    if (missing[index]) transaction.set(references[index], pantryItemFields(entry, user.id, null))
                }
            }.await()
        }
    }

    override suspend fun remove(spaceId: String, ids: List<String>) = runPantryOperation {
        requireVerifiedUser()
        ids.filter(String::isNotEmpty).distinct().chunked(MAX_BATCH_DELETES).forEach { chunk ->
            val batch = firestore.batch()
            chunk.forEach { batch.delete(pantryCollection(spaceId).document(it)) }
            batch.commit().await()
        }
    }

    private fun pantryCollection(spaceId: String) = firestore.collection(SPACES)
        .document(spaceId).collection(PANTRY_ITEMS)

    private fun requireVerifiedUser(): AuthUser {
        val user = authRepository.currentUser.value
            ?: throw PantryRepositoryException(PantryFailure.NotAuthenticated)
        if (!user.isEmailVerified) throw PantryRepositoryException(PantryFailure.EmailNotVerified)
        return user
    }

    private suspend inline fun <T> runPantryOperation(crossinline operation: suspend () -> T): T =
        syncRepository.runWriteOperation(
            isNetworkFailure = { it.failure == PantryFailure.Network },
            networkException = { PantryRepositoryException(PantryFailure.Network, it) },
            toException = Throwable::toPantryRepositoryException,
            operation = operation,
        )

    private companion object {
        const val SPACES = "spaces"
        const val MAX_PANTRY_ITEMS = 1000L
        const val MAX_ADDS_PER_TRANSACTION = 100
        const val MAX_BATCH_DELETES = 400
    }
}

private fun Throwable.toPantryRepositoryException() = this as? PantryRepositoryException ?: PantryRepositoryException(
    failure = when ((this as? FirebaseFirestoreException)?.code) {
        FirebaseFirestoreException.Code.PERMISSION_DENIED -> PantryFailure.PermissionDenied
        FirebaseFirestoreException.Code.UNAVAILABLE -> PantryFailure.Network
        else -> PantryFailure.Unknown
    },
    cause = this,
)
```

```kotlin
/** Lo que hay que escribir en la Compra para apuntar lo que se ha acabado, y lo que ya estaba pendiente (no se escribe). */
internal data class PantryRestock(val writes: List<ShoppingWrite>, val alreadyListed: List<String>)

/**
 * «A la compra» de [names] contra la lista [items] (léase del servidor): pendiente → no se escribe; comprado → se vuelve
 * a apuntar conservando cantidad, notas, tienda y marca; si no está → se añade sin cantidad, con la marca y la tienda
 * por defecto (ver `defaultSelection`). Los nombres en blanco y los repetidos por clave se ignoran.
 */
internal fun pantryRestock(names: List<String>, items: List<ShoppingItem>, data: IngredientShoppingData): PantryRestock {
    val writes = mutableListOf<ShoppingWrite>()
    val alreadyListed = mutableListOf<String>()
    names.map(String::trim).filter(String::isNotEmpty).distinctBy(::shoppingMatchKey).forEach { name ->
        val match = findShoppingMatch(items, name)
        when {
            match == null -> writes += newShoppingWrite(name, data)
            match.purchased -> writes += ShoppingWrite.Change(
                seen = match,
                quantity = match.quantity,
                notes = match.notes,
                supermarket = match.supermarket,
                brand = match.brand,
                relist = true,
            )
            else -> alreadyListed += match.name
        }
    }
    return PantryRestock(writes, alreadyListed)
}

private fun newShoppingWrite(name: String, data: IngredientShoppingData): ShoppingWrite.Add {
    val context = data.contextFor(name)
        ?: return ShoppingWrite.Add(name = name, quantity = null, notes = null, supermarket = null, brand = null)
    val selection = context.defaultSelection()
    return ShoppingWrite.Add(
        name = name,
        quantity = null,
        notes = null,
        supermarket = selection.store,
        brand = context.brandName(selection),
    )
}
```

```kotlin
package com.dlunaunizar.bobitos.feature.pantry

import com.dlunaunizar.bobitos.core.common.prepareQuery
import com.dlunaunizar.bobitos.core.model.INGREDIENT_CATEGORIES
import com.dlunaunizar.bobitos.core.model.PantryItem
import java.text.Collator
import java.util.Locale

/** Un grupo de la Despensa: [category] es una de las 14 del catálogo, o `null` para «Otros» (siempre al final). */
internal data class PantryGroup<T>(val category: String?, val items: List<T>)

// Compartido entre llamadas: RuleBasedCollator.compare está sincronizado.
private val PANTRY_COLLATOR: Collator =
    Collator.getInstance(Locale.forLanguageTag("es-ES")).apply { strength = Collator.PRIMARY }

/** Agrupa por las categorías del catálogo, en su orden; lo demás (sin categoría o con otra) va a «Otros». */
internal fun <T> groupByIngredientCategory(
    items: List<T>,
    category: (T) -> String?,
    name: (T) -> String,
): List<PantryGroup<T>> {
    val byCategory = items.groupBy { item -> category(item)?.takeIf { it in INGREDIENT_CATEGORIES } }
    val byName = Comparator<T> { a, b -> PANTRY_COLLATOR.compare(name(a), name(b)) }
    return (INGREDIENT_CATEGORIES + null).mapNotNull { key ->
        byCategory[key]?.let { PantryGroup(key, it.sortedWith(byName)) }
    }
}

/** La lista de la Despensa: lo que coincide con [query] (por nombre o categoría), agrupado. */
internal fun pantrySections(items: List<PantryItem>, query: String): List<PantryGroup<PantryItem>> {
    val search = prepareQuery(query)
    return groupByIngredientCategory(
        items.filter { search.matches(it.name, it.category) },
        PantryItem::category,
        PantryItem::name,
    )
}
```

```kotlin
@HiltViewModel
class PantryViewModel @Inject constructor(

    private val shoppingRepository: ShoppingRepository,
    private val ingredientSource: IngredientShoppingSource,

    val uiState: StateFlow<PantryUiState> = mutableUiState.asStateFlow()
    private var itemsJob: Job? = null
    private var observedSpaceId: String? = null

    fun observe(spaceId: String) {
        if (spaceId == observedSpaceId && itemsJob?.isActive == true) return
        itemsJob?.cancel()
        observedSpaceId = spaceId
        mutableUiState.update { it.copy(items = UiState.Loading) }
        itemsJob = viewModelScope.launch {
            repository.items(spaceId)
                // Sin el texto de la excepción: la pantalla dice que no se ha podido leer y ofrece «Reintentar».
                .catch { mutableUiState.update { state -> state.copy(items = UiState.Error()) } }
                .collect { items -> mutableUiState.update { it.copy(items = UiState.Content(items)) } }
        }
    }

    fun stopObserving() {
        itemsJob?.cancel()
        itemsJob = null
        observedSpaceId = null
    }

    fun setQuery(query: String) = mutableUiState.update { it.copy(query = query) }

    /** «Se acabó»: quita [item]; cuando se confirma, la pantalla ofrece apuntarlo a la compra ([PantryUiState.finished]). */
    fun markFinished(item: PantryItem) {
        val spaceId = observedSpaceId ?: return
        runAction(onSuccess = { it.copy(finished = item) }) {
            repository.remove(spaceId, listOf(item.id))
            null
        }
    }

    fun consumeFinished() = mutableUiState.update { it.copy(finished = null) }

    /** «A la compra»: apunta [item] en la Compra (ver [pantryRestock]); si ya estaba pendiente, solo lo avisa. */
    fun restock(item: PantryItem) {
        val spaceId = observedSpaceId ?: return
        runAction {
            // La lista del servidor, no la caché: con una vieja se duplicaría el artículo.
            val items = shoppingRepository.currentItems(spaceId)
            val plan = pantryRestock(listOf(item.name), items, ingredientData())
            if (plan.writes.isEmpty()) {
                PantryUiMessage.AlreadyInShopping
            } else {
                shoppingRepository.applyWrites(spaceId, plan.writes)
                PantryUiMessage.AddedToShopping
            }
        }
    }

    fun clearFeedback() = mutableUiState.update { it.copy(error = null, notice = null) }

    // Marcas y tiendas para un artículo nuevo; si no llegan a tiempo, se apunta sin marca ni tienda.
    private suspend fun ingredientData(): IngredientShoppingData =
        withTimeoutOrNull(CATALOG_TIMEOUT_MILLIS) { ingredientSource.data().first() } ?: IngredientShoppingData()

    // Ejecuta [action] (devuelve el aviso de éxito) y, si sale bien, aplica [onSuccess] al estado.
    private fun runAction(
        onSuccess: (PantryUiState) -> PantryUiState = { it },
        action: suspend () -> PantryUiMessage?,
    ) {
        if (mutableUiState.value.isSaving) return
        mutableUiState.update { it.copy(isSaving = true, error = null, notice = null) }
        viewModelScope.launch {
            runCatching { action() }
                .onSuccess { notice -> mutableUiState.update { onSuccess(it.copy(isSaving = false, notice = notice)) } }
                .onFailure { error ->
                    if (error is CancellationException) throw error
                    mutableUiState.update { it.copy(isSaving = false, error = error.toUiMessage()) }
                }
        }
    }
}

private fun Throwable.toUiMessage(): PantryUiMessage = when (this) {
    is PantryRepositoryException -> when (failure) {
        PantryFailure.NameRequired -> PantryUiMessage.NameRequired
        PantryFailure.NameTooLong -> PantryUiMessage.NameTooLong
        PantryFailure.NotAuthenticated -> PantryUiMessage.NotAuthenticated
        PantryFailure.EmailNotVerified -> PantryUiMessage.EmailNotVerified
        PantryFailure.SpaceNotFound -> PantryUiMessage.SpaceNotFound
        PantryFailure.PermissionDenied -> PantryUiMessage.PermissionDenied
        PantryFailure.Network -> PantryUiMessage.NetworkError
        PantryFailure.Unknown -> PantryUiMessage.UnexpectedError

    is ShoppingRepositoryException -> when (failure) {
        ShoppingFailure.ItemChanged, ShoppingFailure.ItemNotFound -> PantryUiMessage.ShoppingChanged

        ShoppingFailure.EmailNotVerified -> PantryUiMessage.EmailNotVerified
        ShoppingFailure.SpaceNotFound -> PantryUiMessage.SpaceNotFound
        ShoppingFailure.PermissionDenied -> PantryUiMessage.PermissionDenied
        ShoppingFailure.Network -> PantryUiMessage.NetworkError
        else -> PantryUiMessage.UnexpectedError
    }
    else -> PantryUiMessage.UnexpectedError
}
```

```kotlin
import com.dlunaunizar.bobitos.core.model.CatalogIngredient
import com.dlunaunizar.bobitos.core.model.MAX_PANTRY_NAME_LENGTH
import com.dlunaunizar.bobitos.core.model.PantryEntry

/** Una fila del selector: lo que se apuntaría, su id y si ya está en la despensa (sale marcada y deshabilitada). */
internal data class PantryPickRow(val entry: PantryEntry, val id: String, val inPantry: Boolean)

/** El selector: los ingredientes agrupados y, si lo escrito no es ninguno, la fila para apuntarlo tal cual. */
internal data class PantryPickerContent(val groups: List<PantryGroup<PantryPickRow>>, val freeText: PantryPickRow?)

internal fun pantryPickerContent(
    ingredients: List<CatalogIngredient>,
    pantryIds: Set<String>,
    query: String,
): PantryPickerContent {
    val rows = ingredients.matching(query)
        .map { PantryPickRow(PantryEntry(it.name, it.category), pantryId(it.name), pantryId(it.name) in pantryIds) }
        .filter { it.id.isNotEmpty() }
        .distinctBy(PantryPickRow::id)
    return PantryPickerContent(
        groups = groupByIngredientCategory(rows, { it.entry.category }, { it.entry.name }),
        freeText = freeTextRow(ingredients, pantryIds, query),
    )
}

// Lo escrito, si no es un ingrediente (por clave tolerante) ni algo que ya está, y se puede apuntar.
private fun freeTextRow(ingredients: List<CatalogIngredient>, pantryIds: Set<String>, query: String): PantryPickRow? {
    val text = query.trim()
    val id = pantryId(text)
    val known = id.isEmpty() || id in pantryIds || findByKey(ingredients, text) != null
    return if (known || text.length > MAX_PANTRY_NAME_LENGTH) null else PantryPickRow(PantryEntry(text, null), id, false)
}
```

```kotlin
@Composable
private fun PickerList(
    content: PantryPickerContent,
    selected: Set<String>,
    onToggle: (PantryEntry) -> Unit,
    modifier: Modifier = Modifier,
) {
    LazyColumn(modifier) {
        content.freeText?.let { row ->
            item(key = "free-${row.id}") {
                PickRow(
                    label = stringResource(R.string.pantry_picker_free_text, row.entry.name),
                    checked = row.id in selected,
                    enabled = true,
                    onToggle = { onToggle(row.entry) },
                )
            }
        }
        content.groups.forEach { group ->
            item(key = "h-${group.category}") {
                Text(
                    text = group.category ?: stringResource(R.string.pantry_others),
                    style = MaterialTheme.typography.titleSmall,
                    color = MaterialTheme.colorScheme.primary,
                    modifier = Modifier.padding(top = Spacing.md, bottom = Spacing.xs),
                )

            items(group.items, key = PantryPickRow::id) { row ->
                PickRow(
                    label = row.entry.name,
                    checked = row.inPantry || row.id in selected,
                    enabled = !row.inPantry,
                    onToggle = { onToggle(row.entry) },
                )
            }
        }
    }
}

@Composable

    ) {
        Checkbox(checked = checked, onCheckedChange = null, enabled = enabled)
        Text(label, style = MaterialTheme.typography.bodyLarge, modifier = Modifier.padding(start = Spacing.sm))
    }
}
```

```kotlin
// Avisos de éxito como Snackbar efímero; «Se acabó», con la acción «A la compra» durante más tiempo.
@Composable
private fun PantrySnackbars(
    state: PantryUiState,
    host: SnackbarHostState,
    onNoticeShown: () -> Unit,
    onFinishedShown: () -> Unit,
    onRestock: (PantryItem) -> Unit,
) {
    val noticeText = state.notice?.let { stringResource(it.stringRes()) }
    LaunchedEffect(state.notice) {
        val text = noticeText ?: return@LaunchedEffect
        host.showSnackbar(text)
        onNoticeShown()
    }
    val finished = state.finished
    val finishedText = finished?.let { stringResource(R.string.pantry_finished_snackbar, it.name) }
    val toShopping = stringResource(R.string.pantry_to_shopping)
    LaunchedEffect(finished) {
        if (finished == null || finishedText == null) return@LaunchedEffect
        val result = host.showSnackbar(finishedText, actionLabel = toShopping, duration = SnackbarDuration.Long)
        onFinishedShown()
        if (result == SnackbarResult.ActionPerformed) onRestock(finished)
    }
}
```
